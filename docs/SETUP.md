# Knowledge Base Hub — Setup Guide

## Prerequisites

Install:

- Python 3.12 or compatible version
- Git
- Ollama

## 1. Clone Repository

```powershell
git clone https://github.com/dhanavishva27/knowledge-base-hub.git
cd knowledge-base-hub
```

## 2. Create Virtual Environment

```powershell
python -m venv venv
```

Activate:

```powershell
venv\Scripts\activate
```

## 3. Install Python Dependencies

```powershell
pip install -r requirements.txt
```

## 4. Database Setup

```powershell
python manage.py migrate
```

## 5. Create Admin User (Optional)

```powershell
python manage.py createsuperuser
```

## 6. Install and Prepare Ollama

Install Ollama and ensure it is running.

Pull the required model:

```powershell
ollama pull llama3.2:3b
```

Optional test:

```powershell
ollama run llama3.2:3b
```

## 7. Run Django

```powershell
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000/
```

## 8. Upload Knowledge Sources

Open:

```text
http://127.0.0.1:8000/upload/
```

Upload a CSV/XLSX file containing a `URL` column.

The application automatically performs:

```text
URL extraction
→ scraping
→ cleaning
→ chunking
→ embedding
→ FAISS indexing
```

## 9. Search

Open:

```text
http://127.0.0.1:8000/
```

Enter a natural-language question.

Example:

```text
Who is the CEO of Apple?
```

## 10. API Testing

Open:

```text
http://127.0.0.1:8000/api/urls/
```

or:

```text
http://127.0.0.1:8000/api/search/?q=Who%20is%20the%20CEO%20of%20Apple?
```

## 11. Useful Development Commands

```powershell
python manage.py check
python manage.py makemigrations
python manage.py migrate
python manage.py runserver
python manage.py shell
```

## 12. Runtime Requirements

Ollama must be available when using the RAG search functionality.

The embedding model may be downloaded by Sentence Transformers on first use.

The FAISS index is generated by the ingestion/indexing pipeline and is intentionally excluded from Git in the current project configuration.
